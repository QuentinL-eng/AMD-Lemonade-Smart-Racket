# Tennis Buddee logo

The mark is a lowercase "b" drawn as a racket, with a speech-bubble tennis ball: the buddy who explains your game.

## Files

| File | Use |
|---|---|
| `svg/tennis-buddee-icon.svg` | App icon with rounded corners. For websites, decks, social. |
| `svg/tennis-buddee-icon-square.svg` | App icon with square corners. For the App Store and Xcode, which round the corners for you. |
| `svg/tennis-buddee-mark-on-dark.svg` | The "b" + ball alone, cream "b". Put it on dark backgrounds. |
| `svg/tennis-buddee-mark-on-light.svg` | The "b" + ball alone, green "b". Put it on light backgrounds. |
| `svg/tennis-buddee-lockup-on-light.svg` | Icon + name, green name. For light backgrounds. |
| `svg/tennis-buddee-lockup-on-dark.svg` | Icon + name, cream name. For dark backgrounds. |
| `svg/tennis-buddee-wordmark-on-*.svg` | The name alone. |
| `png/` | The same files as PNGs with transparent backgrounds. The size is in the file name. |

The name is traced to shapes in every SVG, so it looks the same with or without the font installed.

## Colors

| Name | Hex | Use |
|---|---|---|
| Optic yellow | `#D6F23F` | The ball |
| Deep court green | `#0B2E22` | Icon background, seams, name on light backgrounds |
| Cream | `#F4F6EC` | The "b", name on dark backgrounds |

## Font

Archivo, width 125, weight 800, letter spacing -0.01em. Free from Google Fonts (SIL Open Font License).

## Rules

- Keep space around the logo equal to at least the height of the ball.
- Do not stretch, rotate or recolor the mark.
- Under 32 px, use the icon alone, not the lockup.
